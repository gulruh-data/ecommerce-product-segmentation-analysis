# 📈 E-Commerce Product Segmentation & Performance Analysis

## 🎯 Project Overview
Bu proje, işletmenin ürün portföyünü ciro ve satış hacmi üzerinden segmentlere ayırarak stratejik karar destek mekanizması oluşturmayı hedefler.

## 🛠️ Tech Stack & Skills
- **Tool:** Google BigQuery
- **Advanced SQL Techniques:** - `CTE (Common Table Expressions)`: Okunabilir ve modüler kod yapısı.
  - `Segmentation (CASE WHEN)`: Ürünlerin performans sınıflarına ayrılması.
  - `Window Functions`: Toplam ciro içindeki yüzde pay hesaplamaları.

## 🔍 Business Logic
1. **Data Aggregation:** Ürün bazlı satış hacmi ve gelir metrikleri birleştirildi.
2. **ABC Analysis:** Ürünler, getirdikleri ciroya göre A, B ve C sınıflarına ayrılarak stok önceliklendirmesi sağlandı.
3. **Market Share Calculation:** Her bir ürünün genel şirket cirosu içindeki ağırlığı analiz edildi.
